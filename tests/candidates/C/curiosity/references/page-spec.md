# 交互页面规范

制作或更新交互页时读取。围绕一个理解目标组织：原问题、必要图示与操作、随状态改变的解释、模型假设与来源。当前对话的语言负担、术语释义、局部已知和必要条件延续到页面，不要求逐句相同。不要预建年龄或难度切换系统。

## 交付

- 单文件 `curiosity-<主题>.html`，内联 CSS、JS、SVG／Canvas，直接打开即可使用。不要外部资源、联网请求或外链跳转；页面来源用文本，聊天另给可核验链接。
- 只开放当前目标必需的变量，操作后数值、图形、状态和解释同步。可直接操作；预测题如有必须可跳过。
- 桌面及 375px 窄屏可读、不横溢；控件有标签、可触控及键盘操作，有焦点提示，不只靠颜色传达状态。必要时使用简短读屏状态，避免每次拖动读出整页。
- 尊重减少动态效果偏好。无必要的装饰动画删去。
- 修改现有页面时核对实际文件与用户意图，避免覆盖无关产物。更新后复验受影响的状态及说明。

## 模型先于画面

制作前核验公式、单位、假设、趋势、临界点与可操作范围。明确哪些条件被省略，图示不能伪装为完整现实模拟。自拟算例用来查实现，不当成现实证据。

### 浮沉样板的唯一教学模型

水平、直立、刚性、不漏水的敞口长方形容器，水面静止；忽略波浪、侧翻、变形与进水后的运动。令水平截面积 A、外底至船口高度 H、船体与货物总质量 m、水密度 ρ。

静态吃水 d=m/(ρA)。只有 d<H 时显示漂浮平衡，此时浮力等于总重量；d≥H 显示“到达／超过进水边界”，停止给出稳定漂浮或进水后运动结论。边界总质量为 ρAH，质量条统一用 kg，不能叫“当前排水量”或真实船舶安全载荷。

样板固定 A=2 m²、H=0.5 m、ρ=1000 kg/m³；船体自重选定并明确，货物质量独立显示，总质量为两者相加。m=500 kg 时 d=0.25 m，m=1000 kg 达边界，m=1200 kg 超出。零货物状态及控件端点也要核对。超出时可保留临界位置作为示意，但不把按公式外推的 d 称为实际吃水。

依据：得克萨斯大学浮体平衡讲义，https://farside.ph.utexas.edu/teaching/336L/Fluidhtml/node27.html 。该来源支持平衡关系；容器几何与数值为自拟教学设定。

### 影长样板

竖直杆高 h=1 m、水平地面、平行光；光线对水平地面仰角 α。直角三角形 tan(α)=h/L，所以 L=h/tan(α)。操作范围 5°–85°，默认45°；0°公式无有限解，90°为零影长的理想极限，不开放这两个端点。

核对 5°约11.43 m、45°为1 m、85°约0.0875 m；角越大影越短。显示长度与绘图同一比例或明确比例差异，端点不能出框。只改变仰角，不模拟完整太阳路径、散射或半影，不安排直视强光实验。

依据：OpenStax《Algebra and Trigonometry 2e》7.2，https://openstax.org/books/algebra-and-trigonometry-2e/pages/7-2-right-triangle-trigonometry 。教材支持正切关系，影长关系由上述几何假设推得。

## 四层验证与证据

1. 内容与模型：公式、单位、趋势、正常点、临界点、超界、文字与图一致。
2. 浏览器运行：实际打开，检查错误，操作关键控件与端点；桌面、375px、键盘均检查。截图只证明被拍到的画面，不替代操作记录。
3. 离线与操作：无外部请求，主要操作可用，可直接揭示结果。一次运行不外推所有宿主兼容。
4. 用户体验：Computer use 可模拟用户路径与发现可用性问题；真实用户的理解进展、误解减少仍需真人试用，不把智能体体验写成真实儿童效果。

没有实际浏览器证据时标明未运行，检查通过只声明所检查层级，不宣称完整无障碍认证。交付链接指向真实文件，保留当前有效模型与已验证条件。
