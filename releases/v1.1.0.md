# 好奇心 1.1 · v1.1.0

发布日期：2026-10-27。许可证：MIT。版本号以根目录 [VERSION](../VERSION) 为准，Git 标签为 `v1.1.0`；设计稿 V4 与测试候选 E3 是各自的文档／测试标识，不是产品版本号。

本版固化本轮可视化、响应速度与讲解层次的实现调整及验收记录。**发布不等于验收通过：M3 仍未全部通过，速度、默认深度、内容准确性及隐式技能发现仍有已知问题。** 此前仓库实现未设置产品版本标签，本次不补造历史 `v1.0.0` 标签。

## 本版变化

- 聚焦主题默认制作一份可持续更新的 HTML 图解，静态关系图也是有效交付；只有观察条件变化确有帮助时才加入知识交互。
- 要求先在对话中给出有效解释，再制作页面；同主题内容发生纠正时，同步原页受影响的文字、图形、标签和控件状态。
- 默认围绕当前疑问讲解，研究史、特殊体系、精确数字和推导按追问展开；保留专业用户明确要求的深度，尊重纯文字和简短释义偏好。
- 将响应与制作时间纳入要求：有效解释30秒、普通图解120秒、局部释义30秒、旧页小改90秒。这些是验收目标，本版尚未稳定达到。
- 将浮沉／影长的专用教学模型移至按需读取的参考文件，减少其他问题加载的无关内容；没有增加独立评估模型、模板库或额外安全审批。
- 保存 E、E2、E3 的实现快照、失败过程、自然反馈、网页原件、截图和计时，更新策划、实施规划及项目入口。

## 实际验证与限制

本轮用 Computer use 操作 WorkBuddy V5.9.2，界面模型标签为 Deepseek-V4.1-Flash。完成原子／梦境回看及三组既定随机画像，共12条输入；追问依据实际回答产生。没有通过后台接口发送测试输入，没有手修模型生成的网页。

| 观察 | 结果 |
|---|---|
| 显式调用后的主动图解 | 已发生；不能外推为隐式发现也成功 |
| 普通新页交付 | 2分40秒至6分钟，超过120秒目标 |
| 梦境／蘑菇反馈后的原页小改 | 分别77秒、82秒；这两次达到90秒目标 |
| 简短释义／明确公式追问 | 分别8秒、10秒，遵从不改网页的偏好 |
| 镜子首轮 | 等待4分15秒后模拟用户取消；部分HTML不算完成交付 |
| 默认深度与内容关系 | 仍有过度展开、矛盾、过度概括及研究条件失真 |
| 隐式发现 | 群聊首问未加载本技能，显式调用后才加载 |
| 操作者375px检查 | 未取得有效375 CSS像素视口，不能宣称通过 |
| 真人学习效果／跨宿主性能 | 未验证；M4 真人试用未开始 |

结构校验、本地文档链接、冻结哈希及静态外部依赖检查通过，不替代模型行为、科学内容与真人理解效果验证。完整问题样本和下一步最小处理方向见 [E3报告](../tests/exploratory/2026-10-26-E3/REPORT.md)，计时细项见 [timings.json](../tests/exploratory/2026-10-26-E3/timings.json)。原始失败与反馈后恢复分别保留。

## 获取与更新

发布页提供 GitHub 自动生成的源码包，以及 `curiosity-v1.1.0.zip` 和 `SHA256SUMS.txt`。技能包只包含 `curiosity/` 的正文与参考文件，以及 MIT 许可证和版本文件；不包含测试聊天、失败网页、设计档案、个人配置或第三方参考源码。源码包则保留仓库中的设计与评测证据。

使用仓库时，切换到 `v1.1.0` 标签即可获得固定版本；项目内 `.agents/skills/curiosity` 指向唯一的 `curiosity/` 源目录。使用技能包时，解压后将完整 `curiosity` 文件夹放到目标宿主的技能目录，保留 `references/` 的相对路径。替换旧版前保留自己的修改；重新开启会话，并确认宿主实际加载了新版正文。本次发布不会自动安装或长期挂载到本机其他宿主。

本版改变了默认交付：之前部分关系问题可只用文字结束，现在聚焦主题默认制作图解，因此文件与浏览器操作、等待时间可能增加。只想阅读文字时可直接说“这次只用文字，不做网页”。`eli5`／`show-me` 是可选协作技能，不是运行依赖。

文件生成与实际打开验证依赖宿主工具；本轮只验证上述 WorkBuddy 条件，不保证所有宿主、模型或离线环境的实际行为一致。
