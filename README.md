# 好奇心（curiosity）项目

当前项目目录：`/Users/larry/haoqixin/`。这里保存好奇心 Skill 的设计、评审和源码参考材料。

独立 GitHub 仓库：[gethlx/curiosity](https://github.com/gethlx/curiosity)（私有）。本项目只使用自己的 `origin` 远程，不设置其他项目的 `upstream`，不使用子模块。

**接手项目请先读 [项目导航](项目导航.md)**；了解当前方案请读 [V2 设计策划与实现规划](SKILL_DESIGN_V2.md)。V2 文档标注定稿、尚未实施；当前目录没有 Skill 本体。

`storm/`、`curio/` 是源码参考仓库，**不是 Skill，也没有被挂载为 Codex 或 WorkBuddy 技能。** 本项目与共享技能池 `/Users/larry/AI-Tools/shared/skills/` 分开存放。

这两份参考源码保留在本机，由 `.gitignore` 排除，不随本仓库上传。GitHub 中保存设计、评审、分析、来源清单和离线探查材料；源码引用链接指向各参考项目的固定提交。重新克隆本项目后，如需复现离线源码探查，可按 `SOURCES.json` 的来源与提交号另行恢复本地 `storm/`、`curio/`；只阅读设计稿不需要下载它们。
